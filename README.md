# Django-Based Personal CV Project

This is a personal portfolio and CV website built using the **Django** framework. This project was developed as a self-directed challenge to understand the core architecture of Django applications, from initial setup to template integration and backend customization.

## Key Features
*   **Django Framework:** Built from scratch, focusing on best practices for project structure and configuration.
*   **Template Integration:** Integrated a custom frontend template into Django's template engine.
*   **Dynamic Rendering:** Implemented dynamic data handling for specific template elements to learn about context and view processing.
*   **Learning Experience:** Focused on independent problem-solving for deployment, static file management, and core Django setup.

## Technical Details
*   **Backend:** Django (Python)
*   **Frontend:** HTML/CSS/JS (Template-based)
*   **Environment:** Django built-in development server
